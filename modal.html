Technical Implementation

This modal is implemented using CSS fixed positioning with calculated spacing. The modal uses top: 100px, bottom: 100px, left: 15px, and right: 15px to achieve the required spacing from the viewport edges.

The modal body section uses overflow-y: auto to enable vertical scrolling when the content exceeds the available space. The header and footer sections remain fixed at the top and bottom of the modal using flexbox layout.

Scrolling Behavior

The main page body has overflow: hidden applied to prevent scrolling of the background content. This ensures that users can only scroll within the modal itself, creating a focused reading experience.

The scrollbar within the modal is styled with custom colors to provide a polished appearance that matches the overall design. On webkit-based browsers, you'll see a custom styled scrollbar.
